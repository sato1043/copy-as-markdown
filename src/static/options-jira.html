JIRA Settings

Copying current tab link

If a page title starts with [xxx] (e.g. [JIRA-1234] Some Feature Title), the bracketed text becomes the link text and the remainder is appended as plain text: [JIRA-1234](url) Some Feature Title

Removes the last occurrence of - xxx pattern from the page title. For example, Article Title - Jira becomes [Article Title](url). This is applied before bracketed prefix extraction.

Issue detail behavior

When enabled, clicking on an issue row in JIRA timeline will open the issue detail in a new window/tab instead of the default panel view. This setting only affects pages on *.atlassian.net/jira/*.

When enabled, clicking on an issue card in JIRA backlog will open the issue detail in a new window/tab instead of the default panel view. This setting only affects pages on *.atlassian.net/jira/*.

When enabled, hides the inline "Create" button in JIRA backlog to prevent accidental clicks.

When enabled, hides the epic field on backlog issue cards.

When enabled, hides the story point estimate field on backlog issue cards.

Check the tabs you want to hide in the space navigation sidebar.
